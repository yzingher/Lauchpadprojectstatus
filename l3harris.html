L3 Harris / Vertical Stack Assembly

L3H-VS-001
VERTICAL STACK ASSY · CoDR RENDER

PROJECT DESCRIPTION

Automated vertical stack assembly cell for Kovar-ring and brazing-washer components. Vibration-fed singulation feeds parts to a Venturi-actuated assembly station, with multi-material silos holding Kovar rings for sequenced placement.

Built on Digitool, with gantry-driven pick-and-place, vision verification, and a dedicated completion station with operator-held spill cover for safe transit.
