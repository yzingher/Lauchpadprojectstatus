Lockheed Martin / Carbon Fiber Handling System

STARTFEB ’26

CF HANDLING SYSTEM · CoDR RENDER

PROJECT DESCRIPTION

Sheet pick-and-place system for carbon-fiber prepreg layup. Custom 4-zone pneumatic gripper picks up-sheets and down-sheets from sliding presentation drawers, rotates each to the correct orientation, and stacks them into a travelling tray on a conveyor — building a multi-layer recipe automatically.

Built on Digitool, with vision-based size confirmation, stepper-controlled rotation, and recipe-driven sequencing. Single gripper handles both sheet types, with sheet sizes from 2″ to 12″.
