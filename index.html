CF HANDLING SYSTEM · CoDR RENDER

PROJECT DESCRIPTION

Sheet pick-and-place system for carbon-fiber prepreg layup. Custom 4-zone pneumatic gripper picks up- and down-sheets from sliding presentation drawers, rotates each to orientation, and stacks them into a travelling tray.

Built on Digitool, with vision-based size confirmation, stepper-controlled rotation, and recipe-driven sequencing.

SHEET RANGE2″ — 12″
GRIPPER ZONES4 + center
PLATFORMDigitool
SYSTEM COST$60.5K
