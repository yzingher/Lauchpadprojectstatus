mPower / Texas Feeder — Pallet Handling System

MPOWER-TX-001
TEXAS FEEDER · CDR RENDER

PROJECT DESCRIPTION

Automated pallet feeding system for mPower's test cell. A 20-slot stacker holds operator-loaded pallets; a dual-slot elevator transports them to a downstream test stand which locks each pallet in X, Y, Z for testing before returning it to the stacker.

Built on Digitool V2, with Raspberry Pi controls, hierarchical state machines for elevator / stacker / test, redundant optical+magnetic sensors on the spline drive, and CI/CD-driven Python deployment. Targeting TÜV electrical compliance ahead of UIC operator handover.
